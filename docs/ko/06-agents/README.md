# 에이전트

한 번 해 놓고 끝나는 설정을 스스로 유지되는 시스템으로 바꿉니다.

여기까지는 전부 손으로, 느리게나마 할 수 있었습니다. 이 섹션부터는 볼트가 당신의 꾸준함에 기대지 않게 됩니다. 6개월 뒤에도 볼트가 살아 있을 이유는 그것뿐입니다.

위험도 여기에 있습니다. 노트에 쓰기 권한을 가지고, 당신이 자는 동안 스케줄에 따라 돌아가는 에이전트는 들리는 그대로 유용하고, 들리는 그대로 위험합니다. 무엇이든 예약하기 전에 [가드레일](safety-and-guardrails.md)을 읽으십시오.
