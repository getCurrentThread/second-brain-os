# 웹 글

글은 대부분의 사람이 저장하는 자료의 대다수를 차지하고, 저장할지 말지는 브라우저에서 결정됩니다. 창을 바꿔야 하는 방식은 무엇이든 집니다.

<a id="obsidian-web-clipper"></a>

## Obsidian Web Clipper

Obsidian 팀이 만든 [공식 확장 프로그램](https://obsidian.md/clipper)입니다. Chrome, Firefox, Safari, Edge, Brave, Arc를 지원합니다. Firefox 리더 보기와 같은 엔진인 Mozilla Readability로 페이지에서 읽을 만한 본문을 추출해, 마크다운으로 볼트에 곧바로 저장합니다.

설치하고 설정을 열어 저장 폴더를 `raw/`로 지정합니다.

<a id="template"></a>

## 템플릿

기본 템플릿은 페이지 본문을 저장합니다. 에이전트가 파일 전체를 다시 읽지 않고도 무엇을 쥐고 있는지 알 수 있게 프론트매터를 추가합니다.

```
---
title: {{title}}
source: {{url}}
author: {{author}}
published: {{published}}
clipped: {{date}}
type: article
---

{{content}}
```

`{{author}}`와 `{{published}}`는 많은 사이트에서 빈 값으로 돌아옵니다. 괜찮습니다. 빈 필드가 추측한 필드보다 낫고, 에이전트는 날짜를 지어내는 대신 자료에 날짜가 없다고 밝히는 것으로 그 공백을 처리합니다.

<a id="what-to-clip"></a>

## 클리핑할 것

1년 뒤에 다시 찾고 싶을 만한 것을 클리핑합니다. 1차 자료, 엔지니어링 글, 논문, 문서, 동의하지 않아서 나중에 반박하고 싶은 주장.

일주일이면 낡을 뉴스, 리스티클, 죄책감 때문에 저장하는 것은 건너뜁니다. 가치가 낮은 페이지는 인제스트할 때 한 번, 그리고 에이전트가 다른 것을 찾다가 그 페이지를 지나칠 때마다 또 한 번, 비용이 두 번 듭니다.

클리핑하는 순간의 정직한 기준은, 나중에 이 자료에 무엇을 물을지 말할 수 있는가입니다. 말할 수 없다면 클리핑하지 않습니다.

<a id="awkward-pages"></a>

## 까다로운 페이지

- **페이월.** 클리퍼는 브라우저가 렌더링한 것을 저장합니다. 읽을 수 있으면 저장할 수 있습니다. 읽을 수 없으면 페이월 안내문이 저장되므로, 넘어가기 전에 확인합니다.
- **문서 사이트.** 페이지를 하나씩 클리핑하는 것은 이길 수 없는 싸움입니다. 진입점만 저장하고 나머지는 에이전트가 가져오게 하거나, 오픈 소스라면 문서 저장소를 `raw/`에 클론합니다.
- **싱글 페이지 앱과 동적 콘텐츠.** Readability가 가끔 일부만 돌려줍니다. 인제스트 전에 파일을 살펴봅니다.
- **스레드와 댓글 영역.** 가치는 대개 답글에 있는데 클리퍼가 이를 버립니다. 스레드를 직접 복사하거나 스크린샷을 찍어 `raw/assets/`에 넣습니다.

<a id="clip-now-ingest-later"></a>

## 지금 클리핑하고 나중에 인제스트

클리핑과 인제스트는 일부러 별개의 단계로 나눕니다. 낮 동안에는 자유롭게 클리핑하고, 나중에 한 번에 모아 `/ingest`를 실행합니다. 자료를 하나씩 인제스트하면 에이전트는 이번 주에 저장한 세 가지가 같은 아이디어를 다룬다는 점을 알아챌 기회가 없기 때문입니다.
