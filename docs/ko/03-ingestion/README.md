# 인제스트

읽고 보고 쓰는 모든 것을 최대한 적은 마찰로 `raw/`에 모은 다음, 위키가 넘치지 않게 위키로 들여옵니다.

수집은 볼트가 살아남는지를 가르는 부분입니다. 무언가를 본 순간부터 저장하기까지 사이의 단계마다 그만두게 될 지점이 생기므로, 목표는 클릭 한 번 또는 명령 하나, 그것도 언제나 같은 것으로 잡습니다.

뒤쪽 절반도 못지않게 중요합니다. 볼트에 무엇을 먹이느냐가 볼트의 상한을 정합니다. 클리핑한 리스티클(목록 나열식 가벼운 글) 백 편은 얄팍한 페이지 백 개와 아무 말도 하지 않는 그래프를 낳습니다.
