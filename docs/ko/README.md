## 세컨드 브레인

에이전트가 여러분을 위해 만들고 관리하는 지식 베이스를 순수 마크다운으로 구현하는 실습 프로젝트입니다. 열 개의 섹션은 실제로 만들어 가는 순서대로 놓여 있습니다. 패턴을 이해하고, 설정하고, 자료를 먹이고, 모양을 잡고, 그래프가 일하게 만들고, 자동화하고, 질의하고, 거기서 산출물을 꺼내고, 계속 살아 있게 유지하고, 고장 나면 고치는 순서입니다. [로드맵](../ROADMAP.md)은 모든 글을 한곳에 지도로 보여 주며, 새 글을 제안하는 곳이기도 합니다.
