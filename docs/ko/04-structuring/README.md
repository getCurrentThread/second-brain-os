# 구조화

볼트가 그래프가 될지 쓰레기장이 될지 가르는 규칙입니다.

인제스트는 무엇이 들어올지를 정하고, 구조는 그중 무엇이든 다시 나올 수 있는지를 정합니다. 같은 자료 1,000개를 담은 두 볼트가 하나는 연구 파트너가, 다른 하나는 검색도 안 되는 더미가 될 수 있으며, 그 차이는 전적으로 아래 규칙에 있습니다.

여기 있는 모든 것은 `CLAUDE.md`에 들어가야 합니다. 에이전트가 채팅에서 한 번 읽은 규칙은 한 세션만 유지되지만, `CLAUDE.md`에 적힌 규칙은 에이전트가 앞으로 쓰는 모든 페이지에 적용되기 때문입니다.
