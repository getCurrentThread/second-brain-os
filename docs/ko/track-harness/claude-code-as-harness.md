# 하네스로서의 Claude Code

Claude Code는 공부하기에 가장 배울 것이 많은 하네스입니다. Anthropic이 같은 장치를 두 가지 형태로 내놓기 때문입니다. 하나는 터미널 제품이고, 다른 하나는 [Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview)입니다. SDK는 똑같은 루프, 권한 시스템, 컨텍스트 관리를 직접 만드는 에이전트에 쓸 수 있게 해 주는 Python 및 TypeScript 라이브러리입니다. 먼저 [구성 요소 페이지](what-a-harness-is.md)를 읽으십시오. 이 페이지는 각 부분을 구체적인 기능에 연결합니다.

<a id="claudemd-and-memory"></a>

## CLAUDE.md와 메모리

`CLAUDE.md`는 세션을 시작할 때 읽는 일반 마크다운 파일입니다. 프로젝트 규약, 빌드 명령, 하우스 룰을 담습니다. 사용자 수준, 프로젝트 수준, 디렉터리 수준으로 계층을 이루어 합쳐집니다. 자동 메모리 파일이 이를 세션 너머로 확장합니다. 교훈은 이렇습니다. 계속 유지되어야 하는 지시는 매번 다시 입력하는 프롬프트가 아니라 에이전트가 읽는 파일에 둡니다. 모든 것을 프롬프트 하나에 욱여넣는 것보다 이 방식이 왜 나은지는 [컨텍스트 엔지니어링](context-engineering.md)을 보십시오.

<a id="hooks"></a>

## 훅

[훅](https://code.claude.com/docs/en/hooks)은 생명주기 이벤트에 묶인 셸 명령입니다. `PreToolUse`, `PostToolUse`, `SessionStart`, `PreCompact`가 있고, 2026년까지 수십 가지가 더 생겼습니다. 훅은 제안이 아니라 결정적 강제입니다. `PreToolUse` 훅은 위험한 명령을 매번 빠짐없이 막을 수 있지만, 프롬프트 지시는 확률을 낮출 뿐입니다. 경험칙은 판단에는 프롬프트, 정책에는 훅입니다.

<a id="subagents"></a>

## 서브에이전트

서브에이전트는 자기만의 컨텍스트 윈도에서 자기만의 시스템 프롬프트와 도구 제한을 가지고 실행됩니다. 부모는 최종 보고서만 보고 중간의 잡음은 전혀 보지 못합니다. 덕분에 오케스트레이션 트랜스크립트가 깔끔하게 유지되고, 쓸 수 있는 컨텍스트가 사실상 늘어납니다. `.claude/agents/`의 마크다운 파일로 정의하거나, SDK를 통해 코드로 정의합니다.

<a id="skills"></a>

## 스킬

스킬은 `SKILL.md`가 든 폴더이며, 스크립트와 템플릿은 선택 사항입니다. 한 줄짜리 설명만 컨텍스트에 상시 올라가 있고, 본문은 관련될 때 로드됩니다. 지시를 필요할 때 검색해 오는 방식으로, 유능한 에이전트가 자기 매뉴얼에 파묻히지 않게 해 주는 패턴입니다. 문서: [Agent Skills](https://code.claude.com/docs/en/agent-sdk/skills).

<a id="mcp"></a>

## MCP

Claude Code는 MCP 클라이언트입니다. 외부 서버가 내장 도구와 나란히 도구를 제공하며, 프로젝트별 또는 사용자별로 설정합니다. 강력하지만 주된 인젝션 표면이기도 합니다. 자세한 내용은 [도구와 MCP](tools-and-mcp.md)에서 다룹니다.

<a id="permissions"></a>

## 권한

모든 도구 호출은 권한 계층을 거칩니다. `settings.json`의 허용 목록, 호출마다 묻는 프롬프트, `plan` 모드(읽기 전용), 샌드박스 실행이 그것입니다. 설계 전제는 모델이 가끔 어리석은 짓을 한다는 것이고, 그래서 브레이크는 모델이 아니라 하네스가 쥡니다.

<a id="headless-and-sdk-use"></a>

## 헤드리스와 SDK 사용

`claude -p "prompt"`는 스크립트와 CI에서 JSON 출력과 함께 한 번만 실행됩니다. Agent SDK는 더 나아갑니다. 간단한 호출에는 `query()`, 훅과 스트리밍에는 클라이언트 클래스가 있고, 서브에이전트와 MCP 서버도 코드로 구성합니다. CLI를 스크립트로 조종하는 것이 아니라 하네스를 내장하는 것입니다.

<a id="the-honest-take"></a>

## 솔직한 평가

2026년 현재 구할 수 있는 가장 완성도 높은 기성 하네스이며, 이 분야의 나머지가 자신을 정의할 때 기준으로 삼는 어휘이기도 합니다. [지형](harness-landscape.md)을 보십시오. 대가는 Anthropic의 설계 방침과 토큰 소모량을 물려받는다는 것입니다. 대부분의 개발자에게는 괜찮은 거래입니다.
