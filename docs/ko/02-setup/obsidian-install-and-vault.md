# Obsidian과 첫 볼트

Obsidian은 시스템의 저장을 맡은 절반입니다. 무료이고, 모든 것을 내 기기의 일반 텍스트 파일로 보관하며, 노트 사이의 링크를 그래프로 그려 줍니다. 어떤 회사의 클라우드에도 저장되지 않고, 언젠가 앱을 떠나더라도 파일은 어떤 텍스트 편집기에서든 읽을 수 있습니다.

<a id="install"></a>

## 설치

[obsidian.md](https://obsidian.md)에서 내려받아 설치합니다.

[README](../../../README.md)의 퀵스타트를 실행했다면 시작용 구조가 들어 있는 `~/brain` 폴더가 이미 있습니다. 시작 화면에서 **Open folder as vault**를 클릭하고 그 폴더를 고르십시오.

아무것도 없이 시작한다면 대신 **Create new vault**를 클릭합니다. 자주 입력할 짧은 이름을 붙이십시오. `brain`이면 됩니다. 기기에서 폴더를 고르고 **Create**를 클릭한 다음, [`vault-template/`](../../../vault-template/)의 내용을 그 안에 복사합니다.

어느 쪽이든 그 폴더가 이제 세컨드 브레인입니다. 에이전트가 쓰는 모든 것이 마크다운 파일로 그곳에 쌓입니다.

<a id="make-one-note-by-hand"></a>

## 직접 노트 하나 만들기

무엇이든 자동화하기 전에 한 번 해 보십시오. 그러면 작동 원리가 추상적이지 않게 됩니다.

새 노트 아이콘을 클릭하고, 문장을 하나 입력한 다음 `[[goals]]`를 입력합니다. 대괄호로 감싼 단어는 `goals`라는 페이지로 가는 링크가 되며, 그 페이지가 아직 없어도 마찬가지입니다. 클릭하면 Obsidian이 페이지를 만들어 줍니다.

이것이 데이터 모델의 전부입니다. 노트가 노트를 가리킵니다. 에이전트가 나중에 하는 모든 일은 이것을 대량으로, 사용자가 직접 하지 않고 하는 것입니다.

<a id="where-to-put-the-vault"></a>

## 볼트를 둘 곳

터미널에서 입력할 수 있는, 경로가 안정적인 곳입니다. 클라우드 동기화 클라이언트가 공격적으로 덮어쓰는 폴더는 피하십시오. 에이전트가 파일을 쓰는 동안 동기화 클라이언트가 그 파일을 덮어쓰면 정리하기 정말 고통스러운 충돌 사본이 생기기 때문입니다. 통하는 선택지는 [Git과 동기화](git-and-sync.md)를 보십시오.

폴더 이름에는 공백을 넣지 마십시오. 이 경로를 명령에 붙여 넣게 됩니다.

<a id="settings-worth-changing-now"></a>

## 지금 바꿔 둘 설정

- **Files and links → New link format:** 상대 경로나 최단 경로 중 하나로 일관되게 정합니다. 링크 형식이 섞여 있으면 이름을 바꾼 뒤 링크가 깨지는 가장 흔한 원인이 됩니다.
- **Files and links → Automatically update internal links:** 켜기.
- **Editor → Show frontmatter:** 켜기. 적어도 처음 몇 주 동안은 에이전트가 쓰는 메타데이터를 눈으로 확인하는 편이 좋습니다.
