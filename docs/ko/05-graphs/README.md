# 그래프

대부분의 세컨드 브레인 안내서가 건너뛰는 부분입니다. 그래프 뷰를 열어 보라고 하고, 뇌처럼 생겼다고 말한 뒤 넘어갑니다.

그래프는 장식이 아닙니다. 검색 인덱스로는 답할 수 없는 질문에 위키가 답할 수 있게 하는 자료 구조입니다. 측정할 수 있는 속성이 있고, 알아볼 수 있는 실패의 모양이 있으며, 눈으로 보는 것 말고도 쓸 곳이 많습니다.

이 섹션은 그래프가 실제로 무엇에 쓰이는지, 어떻게 읽는지, 링크에 의미를 싣는 방법, 그리고 그래프의 일부를 마크다운보다 더 강력한 도구로 옮겨야 하는 때를 다룹니다.
