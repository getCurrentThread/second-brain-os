숫자 네 개를 매달 확인합니다. 시간에 따른 방향이 시스템이 제대로 돌아가는지 알려 주는데, 날마다 쓰다 보면 이것은 분명히 드러나지 않습니다.

<a id="orphan-rate"></a>

## 고아 페이지 비율

들어오는 링크가 없는 페이지가 전체 페이지에서 차지하는 비율입니다.

볼트에서 진단에 가장 쓸모 있는 단일 숫자입니다. 고아 페이지 비율이 오른다는 것은 인제스트가 페이지를 연결하지 않고 쓰고 있다는 뜻이며, 위키를 다시 폴더로 되돌리는 바로 그 실패 모드입니다.

5% 미만이면 건강합니다. 15%를 넘으면 습관이 아니라 인제스트 지시문 어딘가가 고장 난 것입니다.

<a id="average-degree"></a>

## 평균 차수

페이지당 링크 수입니다.

2 미만이면 그래프는 거의 연결되지 않은 것이어서, 그래프를 따라 찾아봐야 단순 검색보다 나을 것이 없습니다. 3에서 8 사이가 개인 볼트의 작업 범위입니다. 10을 한참 넘으면 링크를 장식용으로 더하고 있는 것은 아닌지 확인하십시오. 숫자는 부풀리면서 그래프는 덜 쓸모 있게 만듭니다.

페이지 수와 함께 지켜보십시오. 볼트가 두 배가 되어도 차수가 그대로라면 괜찮습니다. 차수가 떨어진다면 새 페이지가 기존 페이지보다 덜 연결되고 있다는 뜻입니다.

<a id="component-count"></a>

## 연결 요소 수

끊어진 섬이 몇 개인가입니다.

이상적으로는 대부분의 페이지를 가진 큰 연결 요소 하나와, 정말로 별개인 소수의 주제입니다. 주 연결 요소에 든 페이지가 약 80%에 못 미치면 볼트는 조각나 있는 것이고, 아무 이상이 보이지 않는 채로 답이 체계적으로 불완전해집니다.

<a id="stale-page-rate"></a>

## 오래된 페이지 비율

`updated` 날짜가 90일보다 오래된 개념 페이지가 개념 페이지 전체에서 차지하는 비율입니다.

어느 정도의 낡음은 맞습니다. 확정된 생각을 잘 써 둔 페이지는 손댈 필요가 없습니다. 그러나 원본 자료는 계속 들어오는데 대부분의 개념 페이지가 몇 달째 손길을 받지 못했다면, 새 자료가 기존 페이지를 갱신하지 않고 새 페이지로 떨어지고 있다는 뜻입니다. 그렇게 해서 한 가지에 대한 페이지가 네 개가 됩니다.

```dataview
TABLE updated FROM "wiki/concepts"
WHERE updated < date(today) - dur(90 days)
SORT updated ASC
```

<a id="what-not-to-track"></a>

## 추적하지 말아야 할 것

페이지 수와 단어 수입니다. 볼트가 나아지든 말든 둘 다 오르기 때문에, 뿌듯하지만 쓸모없습니다. 페이지가 두 배가 되면서 고아 페이지 비율도 두 배가 된 볼트는 나빠진 것입니다.

<a id="recording-them"></a>

## 기록하기
