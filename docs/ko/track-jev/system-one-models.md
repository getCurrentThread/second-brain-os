# 시스템 1 모델

오늘날 대부분의 AI 제품은 대규모 언어 모델 위에 만들어집니다. 텍스트를 보내면 모델이 토큰 하나씩 텍스트를 써서 돌려줍니다. 소프트웨어에 실제로 필요한 것이 결정 하나뿐일 때는 이 방식이 느리고 비쌉니다. "시스템 1 모델"은 새로운 범주입니다. 2026년 9월 15일 TypeSafe AI가 Jev라는 모델과 함께 내놓았고, 바로 그 틈, 곧 느린 텍스트 생성 대신 빠르고 타입 있는 결정을 위해 만들어졌습니다.

이 주제의 강좌 쪽 내용은 [모듈 3: 값싼 결정](../course-3-gate/cheap-decisions.md)입니다. 이런 부류의 모델이 대개 맡게 되는 게이트 패턴을 다룹니다.

<a id="the-kahneman-framing"></a>

## 카너먼의 틀

이름은 Daniel Kahneman의 *Thinking, Fast and Slow*에서 빌려 왔습니다. 시스템 1은 빠르고 직관적인 판단이고, 시스템 2는 느리고 숙고하는 추론입니다. 이 틀에서 LLM은 시스템 2 기계입니다. 산문으로 소리 내어 추론합니다. TypeSafe의 주장은, 소프트웨어가 모델에 시키는 일의 상당수(분류, 라우팅, 점수 매기기, 게이트)가 시스템 1의 일이고 거기에 LLM의 지연과 비용을 치르는 것은 낭비라는 것입니다. 창업자 Diogo Almeida(전 OpenAI, RLHF와 ChatGPT 작업에 참여)는 이를 "프런티어 수준 지능의 함수 호출: 비정형 상태가 들어가면 타입 있는 확률적 결정이 나온다"고 부릅니다.

<a id="what-jev-actually-returns"></a>

## Jev가 실제로 돌려주는 것

Jev는 비자기회귀(non-autoregressive) 모델입니다. 텍스트를 아예 생성하지 않습니다. `state`(문자열, JSON 객체, 텍스트 배열)와 타입 있는 질문 하나 이상을 보내면, 모든 질문에 한 번의 병렬 처리로 답합니다. 기본 요소는 세 가지입니다.

- `Choice` — 정의된 최대 255개 선택지 중 하나를 고르고, 선택지마다 확률을 붙입니다
- `Score` — 입력을 2–10단계의 순서 있는 척도 위에 놓습니다
- `Noul` — 0과 1 사이의 확률로 돌려주는 예/아니오 판단

모든 답에는 보정된 확률이 붙습니다. TypeSafe는 이를 RLCD(Reinforcement Learning for Calibrated Decisions)라고 부르는 방법으로 학습시켰는데, 사람 평가자를 흡족하게 하는 것이 아니라 정직한 신뢰도를 최적화합니다.

<a id="honest-caveats"></a>

## 솔직한 단서

출시된 지 며칠밖에 안 됐고, 거의 모든 수치가 공급사 자체 수치입니다.

- 내세우는 주장, 곧 프런티어 LLM보다 대략 200배 빠르고 최대 400배 싸다는 것은 TypeSafe 팀이 직접 만든 벤치마크에서 나온 것이며, 회사도 이것이 상한에 가깝다고 인정합니다.
- "환각 제로"가 실제로 뜻하는 것은 *스키마 밖* 출력이 0이라는 것입니다. Jev는 정의하지 않은 선택지를 지어낼 수 없지만, 틀린 것을 고를 수는 있습니다.
- 아키텍처, 모델 크기, 가중치는 공개되지 않았습니다. 동료 심사를 거친 논문도 아직 없습니다. Anthony Maio 같은 회의론자들이 지적했듯 분포 이동 아래에서의 보정은 입증되지 않았습니다.

독립적인 평가가 나올 때까지는 메커니즘은 실재하는 것으로, 규모는 마케팅으로 보십시오. 어떤 과제에 맞을 법한지는 [Jev가 잘하는 일](what-jev-is-good-for.md)을, 써 보려면 [시작하기](getting-started.md)를, 출처는 [Jev 자료](resources.md)를 보십시오.
