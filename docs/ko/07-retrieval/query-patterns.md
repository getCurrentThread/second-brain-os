# 질의 패턴

어떤 질문은 볼트가 검색 엔진이나 범용 모델보다 훨씬 잘 답합니다. 습관으로 만들 가치가 있는 질문은 바로 이런 것들입니다.

<a id="what-do-i-know-about-x"></a>

## X에 대해 나는 무엇을 아는가

가장 기본적인 질문이며, 대부분의 사람이 볼트를 만드는 이유입니다.

```
What do I know about agent harnesses? Read the concept pages and the sources
behind them. Say where my sources disagree.
```

두 번째 문장이 페이지 하나를 직접 읽는 것보다 낫게 만듭니다. 읽은 모든 것을 통합한 시각, 그리고 드러난 불일치는 어느 한 페이지에도 들어 있지 않습니다.

<a id="what-connects-x-and-y"></a>

## X와 Y를 잇는 것은 무엇인가

검색 인덱스는 전혀 답할 수 없는 질문입니다.

```
What connects retrieval quality and context length in my vault? Show the path
through pages, not just the endpoints.
```

경로를 요구하는 것이 중요합니다. 중간 페이지가 곧 추론이며, 결론만 덩그러니 있을 때와 달리 확인할 수 있습니다.

<a id="what-have-i-changed-my-mind-about"></a>

## 내가 생각을 바꾼 것은 무엇인가

[대체 규칙](../04-structuring/contradictions-and-supersession.md) 덕분에만 가능한 질문입니다.

```
Find pages where a later source superseded an earlier claim. What did I believe,
what changed it, and when?
```

분기마다 돌려 보십시오. 자신의 생각을 바깥에서 지켜보는 일에 가장 가까우며, 모르는 사이에 고친 믿음이 대개 적어도 하나는 드러납니다.

<a id="what-is-missing"></a>

## 빠진 것은 무엇인가

```
Look at my concept pages on prediction markets. What questions do they raise
that no source in my vault answers?
```

이렇게 하면 볼트는 알고리즘이 클릭할 것이라고 짐작하는 글이 아니라, 자신의 빈틈에서 만들어진 읽기 목록이 됩니다.

<a id="what-did-i-say-about-this-before"></a>

## 이에 대해 전에 내가 한 말은 무엇인가

[채팅 내보내기](../03-ingestion/chat-exports.md)를 인제스트해 두었다면 특히 쓸모 있습니다.

```
Have I worked on this problem before? What did I conclude and what did I get
wrong?
```

<a id="what-contradicts-this"></a>

## 이것과 모순되는 것은 무엇인가

```
I am about to argue that X. What in my vault argues against it?
```

이 묶음에서 가장 가치 있으면서 가장 적게 쓰이는 질의입니다. 반박당하겠다고 자원하는 사람은 없기 때문입니다. 나를 확인해 주기만 하는 볼트는 잘못 만든 볼트입니다.

<a id="questions-to-ask-elsewhere"></a>

## 다른 곳에 물어야 할 질문

세계의 현재 상태에 관한 모든 것. 볼트가 아는 것은 자료를 저장한 날 그 자료가 한 말이고, 그 뒤의 일은 알지 못합니다.

모델이 이미 아는 일반적인 모든 것. 문서화가 잘된 개념을 볼트에 처음부터 설명해 달라고 하면, 그냥 답을 받을 때보다 못한 판본을 얻습니다.
