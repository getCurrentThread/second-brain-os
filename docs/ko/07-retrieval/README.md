# 검색

볼트에 실제로 질문하고, 믿을 만한 답을 얻는 방법입니다.

지금까지는 볼트를 만드는 이야기였습니다. 이 절은 매일 하는 일이며, 세컨드 브레인이 설정에 들인 수고가 제값을 하는지, 아니면 어느새 열지 않게 된 보관소가 되는지가 여기서 갈립니다.

이 절 전체의 바탕에는 규칙 하나가 있습니다. 내 노트와 모델의 일반 지식이 섞인 답은 답이 없느니만 못합니다. 어느 쪽이 어느 쪽인지 구별할 수 없기 때문입니다.
